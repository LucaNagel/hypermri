# Contributors

HyperMRI has been developed through research, software-engineering, analysis,
and documentation contributions. The following roster records the public
attribution for contributors reviewed for the first public release.

## Attribution scope

This file is the canonical public contributor roster. It is curated separately
from the private development repository so that aliases and private commit
metadata are not copied automatically. Please report a missing or inaccurate
entry through the public issue tracker before a release.

This roster acknowledges historical contributions to the project. It does not
imply that each contributor's original code remains in the current version.

The roster lists names and available public GitHub or ORCID identifiers without
publishing e-mail addresses.
