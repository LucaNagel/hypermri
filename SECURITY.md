# Security Policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in a public GitHub
issue or discussion. Send a private report to one of the following addresses:

- luca.nagel@protonmail.com
- luca.nagel@posteo.de

Include the affected HyperMRI version or commit, the impact you observed, and
minimal steps to reproduce the problem. Do not include credentials, access
tokens, patient identifiers, or confidential research data. If sensitive
details are necessary to understand the report, first ask how they can be
shared safely.

Security reports are handled on a best-effort basis. The project does not
currently provide a guaranteed response time, support period, or security
service-level agreement.

## Public issues and research data

Public GitHub issues and discussions must not contain patient data, directly
or indirectly identifying metadata, unpublished confidential research data,
credentials, or other sensitive information. Use a synthetic or fully
anonymized minimal example whenever possible.

If sensitive material was posted accidentally, remove it from the public
thread if possible and contact the maintainer privately at one of the addresses
above. Deleting a comment may not remove the information from notifications,
caches, or repository history.

## Supported versions

Until a formal support policy is published, security fixes are evaluated for
the latest release and the current default branch. Older versions may remain
unpatched.
