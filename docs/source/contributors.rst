Contributors
============

HyperMRI is developed by its historical and current contributors. Because the
public repository starts from a reviewed, history-free snapshot, this roster is
the canonical public attribution.

The reviewed roster is maintained once, in the repository-level
`CONTRIBUTORS.md <https://github.com/LucaNagel/hypermri/blob/main/CONTRIBUTORS.md>`_
file. Keeping one source of truth prevents the website, package metadata, and
repository from drifting apart.

If an attribution is missing or should use a different public identifier,
please follow the repository's contribution process rather than publishing
private commit metadata in an issue.
