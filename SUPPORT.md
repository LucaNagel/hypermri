# Support

HyperMRI is maintained as a research and hobby project. Help is provided on a
best-effort basis; response times, fixes, feature delivery, and compatibility
with a particular scanner, dataset, operating system, or dependency version
are not guaranteed.

## Where to ask

- Use GitHub Issues for reproducible bugs, concrete feature requests, and
  documentation problems.
- Use GitHub Discussions for usage questions, ideas, and broader design
  conversations.
- Report suspected security vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md).

Before opening an issue, search existing issues and include:

- the HyperMRI version or commit;
- the Python version and operating system;
- the relevant scanner vendor, sequence, and data format;
- a minimal reproducible example;
- the complete error message or traceback, with sensitive paths and data
  removed.

Never upload patient data, identifying metadata, credentials, or confidential
research data. Prefer synthetic or fully anonymized examples.

## Scope

Community support is not a substitute for independent scientific validation,
professional medical judgment, or vendor support. HyperMRI is not a medical
device and is not intended for clinical diagnosis, treatment decisions, or
other clinical use.
