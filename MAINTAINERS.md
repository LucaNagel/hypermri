# Maintainers

## Current maintainer

- Luca Nagel ([@LucaNagel](https://github.com/LucaNagel))

Luca Nagel is currently the project's sole maintainer. Maintainer
responsibilities include triaging issues, reviewing contributions, defining
the public API and release scope, and coordinating releases and security
responses.

## Release authority

Luca Nagel is the sole release approver for `0.1.0rc1` and `0.1.0`. His explicit
approval is required for code quality, scientific reference values, privacy
review, the public snapshot, and publication. Approval does not replace the
separate requirement to complete the copyright/rights review and satisfy every
release gate documented in `docs/source/development/release.rst`.

Contributions from everyone are welcome. Pull requests must pass the required
automated checks and require approval from the maintainer before they are
merged into the default branch.

Additional maintainers may be added later through an explicit project
decision. Being listed as a contributor or author does not by itself grant
maintainer or release authority.
